Submit

Practice results are self-reported through a pull request. Official results come only from maintainer runs.

Practice split

  • Run the public practice split with your own keys and compute.
  • Open a pull request with the per-case logs (the runs/ output) and the report. Logs are required.
  • If you ran more than once, submit every attempt, not only the best.
  • Results appear on the Practice (self-reported) tab, labelled unverified, until maintainers re-run a random sample.
guardrailbench verify-submission --results runs/<product>/<split>.jsonl --cases cases/practice

Run this before you open the pull request; maintainers run the same check.

Official split

Only maintainers run the hidden split, on their own infrastructure. Vendors never receive it. To have a product included, open an issue titled “Participation: <product>” (see Contact).
