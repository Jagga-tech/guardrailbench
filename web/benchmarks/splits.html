Practice and official splits

You run the public split, we run the hidden one.

Method GitHub Practice data

Overview

Public test sets mislead: detectors have been trained on the benchmarks that ranked them. GuardrailBench copies the SWE-bench model. You run the public practice split; the maintainers run the hidden official split.

Results: the Practice (self-reported) tab of the leaderboard.

Keeping the official split clean

  • Maintainers write the official split, hold it and run it on their own infrastructure. Vendors never receive it.
  • Before each round the SHA-256 of the frozen official split is published, so anyone can check later that no case changed after results came in.
  • Every case carries a canary string that shows if it leaks into training data. Vendors are asked to state their training sources.
  • The official split is refreshed on a schedule, and retired cases move to the practice split.
  • Self-reported practice results sit on a separate, labelled tier until maintainers re-run a random sample.

Twenty sectors

Every v1 case is tagged with one of 20 sectors, and reports break results down by sector with no weighting between them. A pair’s twin shares its attack’s sector. The 20 seed cases have none and show as “unknown”.

Agriculture, education, energy and utilities, finance, general, government, health, HR, insurance, legal, logistics, manufacturing, media and marketing, nonprofit, real estate and construction, research and science, retail, software and IT, telecom, travel and hospitality.

Who wrote the cases

Written fresh, never copied from public datasets. Model-drafted, machine-checked and cross-reviewed; human review of a verified subset is still to come. Non-English cases have had no native-speaker check.
