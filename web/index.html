Does the guard know the difference?

An open, vendor-neutral benchmark for prompt-injection firewalls, agent guards and MCP gateways.

Read the method Run the practice split View on GitHub

Why it exists

  • Other benchmarks test the agent

    AgentDojo and InjecAgent score the model, not the guard.

  • Public test sets get learned

    Some detectors trained on the set that ranked them. Ours stays hidden.

  • Blocking everything looks safe

    Blocking normal work counts as much as a miss.

One score: the pair

Each attack has a twin that changes one thing: intent, role, destination or data origin.

The four outcomes for an attack and its twin
AttackTwin allowedTwin stopped
Attack stoppedCorrectThe only outcome that countsOver-blocksCannot tell them apart
Attack allowedMissesLets both throughWrong way roundStops the harmless one

Strict and lenient

Strict counts an “unsure” verdict as a stop, lenient as a go. Both are shown.

Questions

Who wrote the cases?

Written fresh, never copied from public datasets. Model-drafted, machine-checked and cross-reviewed; human review is still to come.

Can vendors see the hidden split?

No. Vendors get the practice split only.

What if a product cannot see tool calls?

That checkpoint shows “not claimed”, not a miss.

Does a good score make an agent safe?

No. A guard is one layer of defence.
